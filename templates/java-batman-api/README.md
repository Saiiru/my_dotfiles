# Batman API (Java 11 / Spring Boot)

Template de serviço backend “Batman stack”.

## Requisitos
- Java 11 e Maven (via mise: `mise install`)
- Docker opcional para banco

## Comandos (mise)
- `mise run build` – build
- `mise run test` – testes
- `mise run run` – roda o app
- `mise run dev` – roda sem testes
- `mise run init` – baixa dependências

## Estrutura
- `src/main/java` – código
- `src/main/resources` – configs (application.yml)
- `src/test/java` – testes
